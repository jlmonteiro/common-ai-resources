# :material-shield-lock: Security

Standards for authentication, authorization, secrets management, and data protection.

<div class="grid cards" markdown>

- :material-account-key:{ .lg .middle } **Authentication**

    ---

    OAuth 2.0 / OIDC, token handling, session management.

- :material-account-lock:{ .lg .middle } **Authorization**

    ---

    RBAC/ABAC, deny by default, resource ownership.

- :material-key-variant:{ .lg .middle } **Secrets Management**

    ---

    Storage, rotation, what counts as a secret.

- :material-shield-check:{ .lg .middle } **Input Validation**

    ---

    Allowlists, attack prevention (SQLi, XSS, SSRF), validation rules.

- :material-lock:{ .lg .middle } **Data Protection**

    ---

    TLS 1.3, encryption at rest, data classification levels.

- :material-web:{ .lg .middle } **HTTP Headers**

    ---

    HSTS, CSP, X-Frame-Options, Referrer-Policy.
