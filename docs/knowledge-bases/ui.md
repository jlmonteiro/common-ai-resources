# :material-palette-outline: UI

Low-fidelity wireframing using the Markdown-UI DSL — text-based UI specs that live alongside your code.

> Based on [markdown-ui-dsl](https://github.com/MegaByteMark/markdown-ui-dsl) by MegaByteMark — MIT License.

<div class="grid cards" markdown>

- :material-view-dashboard:{ .lg .middle } **Layouts**

    ---

    ROW, COLUMN, CARD, MODAL, HEADER, FOOTER containers with `--- END ---` boundaries.

- :material-form-textbox:{ .lg .middle } **Components**

    ---

    Buttons, inputs, checkboxes, radios, toggles, dropdowns, badges, tabs, tables.

- :material-responsive:{ .lg .middle } **Responsive**

    ---

    Breakpoint directives (`@sm`, `@md`, `@lg`) processed mobile-first.

- :material-sync:{ .lg .middle } **Spec-Code Sync**

    ---

    Two-way binding between `.ui.md` wireframes and framework components.

- :material-file-code:{ .lg .middle } **Frontmatter**

    ---

    Framework, theme, and component path linking via YAML header.

- :material-comment-text:{ .lg .middle } **Hints & Comments**

    ---

    Blockquotes as AI layout hints, HTML comments for human notes.

</div>
