# :material-test-tube: Testing

Standards for test methodology, structure, and practices.

<div class="grid cards" markdown>

- :material-rotate-left:{ .lg .middle } **TDD**

    ---

    Red/Green/Refactor. Never code without a failing test first.

- :material-format-list-checks:{ .lg .middle } **BDD**

    ---

    Given/When/Then structure, descriptive blocks, data-driven.

- :material-triangle-outline:{ .lg .middle } **Test Pyramid**

    ---

    Many unit, some integration, few e2e.

- :material-close-circle-outline:{ .lg .middle } **Negative Testing**

    ---

    At least one negative test per happy path. Never skip.

- :material-cancel:{ .lg .middle } **Mocking Rules**

    ---

    Avoid unless absolutely necessary. Prefer real implementations.

- :material-docker:{ .lg .middle } **Testcontainers**

    ---

    Real infrastructure for integration tests. Same version as production.

</div>
